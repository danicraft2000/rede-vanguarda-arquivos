# Daniel 20 Anos — Projeto da Festa (tema Rede Vanguarda) · 2029

Vídeo de apresentação da **arquitetura da festa de 20 anos** no **Espaço Armazém (Morenos Eventos)** —
R. Jaguaré Mirim, 164 · Vila Leopoldina · São Paulo – SP · 05311-020 — com o tema
**Rede Vanguarda e seus objetos da antiguidade e da atualidade**.

- Vídeo explicativo **sem narração**: só texto e grafismo, no ritmo da música (≈99 BPM; todos os cortes caem no início de um compasso).
- Cenários em **3D** (Three.js) + grafismo **2D** com texto em movimento 3D (estilo After Effects) e transições estilo Premiere
  (faixas arco-íris, o "V" da Vanguarda, anéis e flash).
- 1920×1080, 30 qps, 5min00s (9.018 quadros), música: `daniel_avila - festa projeto tema 5 minutos`.
- Títulos na **ITC Avant Garde Gothic Bold** com o **V** e o **A** alternativos do logotipo Vanguarda
  (`U+E04F` = V, `U+E000` = A).

## Como renderizar

Requisitos: Node 18+, ffmpeg, Chromium do Playwright e Python 3 (`pip install fonttools uharfbuzz`).

A fonte **não** fica no repositório (é comercial): coloque `ITCAvantGardeStd-Bold.ttf` em `festa-20-anos/fontes/`.

```bash
cd festa-20-anos
python3 tools/gerar_svgs.py        # quadros + telões (SVG)
python3 tools/gerar_texto3d.py     # contornos das letras 3D
cd video && npm install
node tools/preview.mjs /tmp/previa cena=salao@0.5      # prévia de um quadro
node tools/renderizar.mjs saida 3 600                  # render (retomável), 3 processos
node tools/progresso.mjs saida/progresso 9018          # quantos quadros já foram
tools/finalizar.sh saida musica.m4a daniel-20-anos.mp4 # junta os blocos e põe a música
```

O material de referência da Rede Vanguarda (logos e fotos dos estúdios em `video/assets/ref/`) pertence à emissora
e é usado aqui só como memória afetiva, num projeto pessoal de fã.
